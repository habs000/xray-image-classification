# MedScanAI: X-Ray Image Classification with Deep Learning

A deep learning project focused on classifying chest X-ray images as either 'Normal' 'Viral Pneumonia' or 'Bacterial Pneumonia' using convolutional neural networks (CNNs).

## Project Objectives

- Develop a binary image classifier using CNNs.
- Improve model performance with data augmentation techniques.
- Evaluate model performance on a publicly available medical dataset.

## Tools and Technologies

- Python
- TensorFlow / Keras
- OpenCV
- Matplotlib and Seaborn

## Dataset

- Chest X-Ray Images (Pneumonia) Dataset from Kaggle  
  Source: https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia

Dataset includes three folders:
- train/
- val/
- test/

Each containing images under `NORMAL`, `Viral PNEUMONIA` or `Bacterial Pneumonia` classes.
